CME-906

Rate Limiting / Connection Throttling

Harden Application Probabilistic Medium Confidence

Description

Limits request rate per client IP or authenticated identity. Mitigates brute force attacks, credential stuffing, and application-level denial of service from single-source attackers. Does not protect against distributed attacks across many source IPs.

CVSS Vector Impacts

Metric Transition Probability Rationale
Availability (A) H → L 50%
Effective against single-source flooding and automated scanning; ineffective against distributed DoS (botnet traffic from thousands of IPs stays under per-IP limits), application-complexity DoS (single expensive request), and connection-level exhaustion (Slowloris)
  • Attack originates from a single source IP or small number of IPs
  • Attack relies on request volume, not request complexity
  • Rate limiting is configured in blocking mode with appropriate thresholds
 Per-IP request throttling caps the rate at which any single source can consume application resources (connections, threads, CPU), preventing single-source request flooding from exhausting capacity for other clients
Attack Complexity (AC) L → H 60%
Effective against single-source brute force and automated credential testing tools; ineffective against distributed credential stuffing using residential proxy rotation or botnet IPs, where each source stays under the per-IP limit
  • Brute force originates from a single source IP or small number of IPs
  • Attacker is not using credential stuffing with known-valid pairs (few attempts needed)
  • Rate limiting applies to authentication endpoints specifically
 Per-IP throttling limits authentication attempts to a rate that makes dictionary and brute force attacks from a single source impractical (e.g., 5 attempts/minute vs thousands/second)

CWE Relationships

CWE-307 CWE-400 CWE-799

Verification

Verify rate limiting is configured in the web server or reverse proxy

$ grep -r 'limit_req_zone' /etc/nginx/ 2>/dev/null
# Expected: limit_req_zone
Platform: linux
$ grep -rE 'mod_ratelimit|mod_evasive' /etc/httpd/conf*/ /etc/apache2/ 2>/dev/null
# Expected: mod_ratelimit
Platform: linux
$ Get-WebConfigurationProperty -Filter 'system.webServer/security/dynamicIpSecurity/denyByConcurrentRequests' -PSPath 'IIS:\Sites\Default Web Site' -Name enabled
# Expected: True
Platform: windows
