CME-904

WAF (Web Application Firewall)

Harden Application Probabilistic Medium Confidence

Description

HTTP-layer filtering that inspects requests for injection, XSS, path traversal, and other OWASP Top 10 patterns. Can operate in blocking or detection mode with OWASP Core Rule Set.

CVSS Vector Impacts

Metric Transition Probability Rationale
Attack Complexity (AC) L → H 70%
OWASP CRS in blocking mode at paranoia level 2+ blocks the majority of automated and scripted attacks; manual bypass by skilled attackers remains possible via encoding evasion, payload obfuscation, and WAF-specific techniques
  • WAF must be in blocking mode, not detection-only
  • OWASP CRS or equivalent ruleset must be loaded and current
  • No direct-to-origin access path exists that bypasses the WAF
  • WAF must cover all application endpoints
 OWASP Core Rule Set signature matching detects and blocks known injection, XSS, path traversal, and protocol violation patterns at the HTTP request layer before they reach the application

CWE Relationships

CWE-79 CWE-89 CWE-94 CWE-78 CWE-22

Verification

Verify WAF is in enforcement mode with rules loaded and blocking common attack payloads
